# 立项报告质量检查清单

生成 Markdown 前完整检查；生成 HTML 后再次检查内容一致性。

## A. 唯一交付物

- [ ] 只生成立项报告，没有额外生成 BRD、需求分析、用户研究、竞品、MVP、评测、PRD 或项目计划报告。
- [ ] 问题定义、证据、竞品、范围、评测和计划均已汇入立项报告正文或附录。
- [ ] Markdown 与 HTML 是同一份报告的两种呈现，结论和数字一致。

## B. 决策有效性

- [ ] 开头一屏能看懂需要决策什么。
- [ ] 明确给出立项、条件立项、转向验证或停止之一。
- [ ] 结论说明为什么、先做什么、投入什么、何时停。
- [ ] 条件立项的每个条件都有 Owner、期限、门槛和失败动作。
- [ ] 转向验证只批准验证投入，没有偷渡完整开发。
- [ ] 决策矩阵权重已结合项目确认，不是机械套用。
- [ ] 红线可单独否决，没有被总分掩盖。

## C. 问题与用户

- [ ] 问题定义中不含预设功能或技术。
- [ ] 用户、场景、任务、阻碍、替代方式和代价清晰。
- [ ] 区分用户说法与实际行为。
- [ ] 说明为什么现在做，以及不行动的代价。
- [ ] 0→1 与存量项目使用了匹配的证据和判断方式。

## D. 证据与来源

- [ ] 关键陈述标明事实、测算、推断、假设或未知。
- [ ] 用户原话、样本量、市场数据、成本和收益均未虚构。
- [ ] 每个关键数字都有来源、时间范围、样本和统计口径。
- [ ] 测算展示公式、假设和敏感性，不冒充实际结果。
- [ ] 相关性没有写成因果。
- [ ] 外部资料优先使用一手来源，并包含链接与访问日期。
- [ ] 证据冲突、反证和局限被明确展示。
- [ ] 重大未知说明了对决策的影响和补齐方式。

## E. 竞品与机会

- [ ] 竞品分析有明确决策目的。
- [ ] 覆盖直接、间接、替代和潜在竞品中的适用类别。
- [ ] 比较的是用户价值、完整旅程和结构性能力，不只是功能数量。
- [ ] 差异化明确回答为谁、解决什么、凭什么是我们。
- [ ] 包含“对手为何成功、我们为何失败”的最强反方论证。

## F. 目标、指标与范围

- [ ] 项目目标描述用户行为或业务结果，不只是上线功能。
- [ ] 指标写明公式、基线、目标、时间窗、数据源和 Owner。
- [ ] 无基线时写建立方式，没有伪造精确目标。
- [ ] 第一阶段只验证一个核心假设或明确的假设组合。
- [ ] POC、原型和 MVP 没有混用。
- [ ] MVP 能形成完整使用或验证闭环。
- [ ] 每个“必须做”都连回假设、痛点、风险或合规要求。
- [ ] 明确列出“不做项”、理由和重启条件。

## G. AI 专项

非 AI 项目标注“不适用”；AI 项目必须全部检查：

- [ ] 证明使用 AI 的必要性，并比较非 AI 替代方案。
- [ ] 明确 AI 做什么、不做什么和最低价值门槛。
- [ ] 数据来源、授权、质量、更新和责任人清晰。
- [ ] 有离线集、关键分群、难例、边界样本和红线样本。
- [ ] 有人工标准、标注一致性或仲裁机制。
- [ ] 有线上指标、回归机制和漂移监控方案。
- [ ] 单次、单用户、规模化成本与延迟已评估。
- [ ] 模型或供应商不可用时有降级方案。
- [ ] 隐私、版权、偏见、越权、提示注入和幻觉等适用风险已检查。
- [ ] AI、规则、人三者责任边界清晰。
- [ ] 低置信度、规则冲突、申诉和高风险决定有人工兜底。

## H. 投入与执行

- [ ] 团队、时间、现金、数据、基础设施和跨团队依赖已列明。
- [ ] 资源数字区分已确认、测算和待报价。
- [ ] 计划体现关键路径和真实资源瓶颈。
- [ ] 可并行团队没有无意义等待瓶颈团队。
- [ ] 每阶段写明验证问题、产出、进入条件、通过门槛和失败动作。
- [ ] 资源按阶段批准，并设置本阶段投入上限。
- [ ] 外部时间窗口有来源和错过代价。

## I. 风险与止损

- [ ] 最大风险不是泛泛的“进度风险”。
- [ ] 每项关键风险有触发信号、预防、兜底和 Owner。
- [ ] 停止条件可观察、带时间窗、可执行。
- [ ] 说明失败后如何降级、转向或复用已有资产。
- [ ] 待决策事项有选项、建议、决策人和截止时间。

## J. 表达与 HTML

- [ ] 先结论后论据，正文服务决策，附录服务复核。
- [ ] 没有把案例项目的品牌、数字或结论复制进当前报告。
- [ ] 图表回答具体决策问题，没有装饰性图表。
- [ ] 无真实数据时没有绘制暗示精确性的比例或趋势。
- [ ] HTML 在桌面端、移动端和打印模式可读。
- [ ] 导航、锚点、折叠内容和进度条正常工作。
- [ ] HTML 中的来源标签和报告来源索引可对应。

## 阻断规则

出现以下任一项时，不得输出“无条件立项”：

- 核心问题没有真实行为证据，也没有可执行补证计划；
- 关键收益只有未经复核的测算；
- 第一阶段没有明确假设或成功门槛；
- 资源、数据、合规或关键依赖没有 Owner；
- AI 项目没有可靠评测、成本边界、安全护栏或人工兜底；
- 没有明确停止条件；
- 存在未处理的致命红线。
