📋 PRD 必须有

  • 一句话定位公式
  • 北极星指标 + ≥2 个反指标
  • 三阶段评审表
  • 交互逻辑表（正常/空/加载/首次）
  • 边界条件矩阵 ≥6 个异常场景

💼 BP 必须有

  • 市场规模（TAM/SAM/SOM）
  • 商业模式画布
  • 财务模型 3 年预测
  • 退出机制

🎯 立项报告必须有

  • ROI 测算
  • 风险矩阵
  • 资源需求
  • Plan B

🔭 竞品报告必须有

  • ≥3 个直接竞品
  • 三层架构对比（功能/体验/商业）
  • 差异化结论

📊 数据规则

  • 不许编造数据
  • 不确定的事实标注「假设/待验证」
  • 市场数据必须标注来源（艾瑞/QuestMobile/Statista/财报）

🛡 盲区对冲（默认开启）

  • 🟥 红队扫描
  • 🟨 反常识扫描
  • 🟩 完美陷阱警报
  • 💜 情绪-事实分层
